# task-aside

Default local base URL: `http://127.0.0.1:3100` (exposes `/health`, `/tasks`, `/tasks/:id`, and `/mcp`).
Global settings and artifacts live under `~/.task-aside/` (`settings.json`, `logs/`, `runs/<task_id>/`).

## Health Check

```sh
curl -s http://127.0.0.1:3100/health
```

Returns service status, enabled transports (`http`, `mcp`, `worker`), worker identity/allowlist, and Supabase task counts.

## Create a Task (HTTP `POST /tasks`)

```sh
curl -s -X POST http://127.0.0.1:3100/tasks \
  -H 'content-type: application/json' \
  -d '{
    "title": "Implement queue consumer",
    "description": "## Notes\n- Execute headlessly",
    "parent_id": null,
    "priority": "P1",
    "execution": {
      "agent": "codex",
      "permission_mode": "workspace"
    }
  }'
```

**Input fields:** (do not pass `id` — `data.id`, timestamps, and trace metadata are auto-generated by the service; optional W3C `traceparent` header propagates `trace_id`)
- `title` *(required)*: non-empty string
- `description` *(required)*: Markdown string
- `parent_id` *(optional)*: UUID v7 string or `null`
- `priority` *(required)*: `P0`, `P1`, `P2`, or `P3`
- `execution` *(required)*: `{ agent: "agy" | "claude" | "codex", model?, effort?, cwd?, permission_mode?: "read-only" | "workspace" | "full", timeout_ms?, session_id? }`

**Status codes:** `201` created, `400` invalid JSON or fields, `404` route not found or HTTP disabled, `502` upstream Supabase error.

## Read Tasks (HTTP `GET /tasks` and `GET /tasks/:id`)

```sh
curl -s 'http://127.0.0.1:3100/tasks?status=completed&agent=codex&limit=20'
curl -s http://127.0.0.1:3100/tasks/01935e8b-0000-7000-8000-000000000000
```

## MCP (`POST /mcp`)

Built-in MCP tools:
- `create_task`
- `get_task`
- `list_tasks`

```sh
# List available tools
curl -s http://127.0.0.1:3100/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

# Call create_task
curl -s http://127.0.0.1:3100/mcp \
  -H 'content-type: application/json' \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "tools/call",
    "params": {
      "name": "create_task",
      "arguments": {
        "title": "Subtask via MCP",
        "description": "- Child work item",
        "parent_id": null,
        "priority": "P2",
        "execution": {
          "agent": "claude"
        }
      }
    }
  }'
```

Validation errors return JSON-RPC error `-32602`; storage/not-found errors return a tool result with `isError: true`.

## Logs & Run Artifacts

- Daily logs: `~/.task-aside/logs/task-aside-YYYY-MM-DD.log`
- Per-run artifacts: `~/.task-aside/runs/<task_id>/` (`prompt.md`, `result.json`, `raw-output.json` or `events.jsonl`, `agent.log`)
